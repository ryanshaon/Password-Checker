# Password Checker

A simple password strength checking project that helps users understand whether a password is weak, medium, or strong based on common security rules.

## Overview

This project checks a password and gives feedback based on basic password security standards. It is useful for learning input validation, conditional logic, string handling, and basic security awareness.

## Features

- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers
- Detects special characters
- Gives strength feedback
- Helps users improve weak passwords

## Tech Stack

- Python
- String handling
- Conditional logic
- Basic security validation

## How to Run

```bash
python main.py
```

If the main file has a different name, run the Python file that contains the password checking logic.

## Example Checks

A strong password usually contains:

- At least 8 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Example:

```text
Weak: password
Medium: Password123
Strong: Password@123
```
